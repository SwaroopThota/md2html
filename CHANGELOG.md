# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - Initial release

### Added

- CLI tool for converting Markdown files to HTML
- File read/write helpers for working with source and output files
- Markdown-to-HTML conversion for headings, paragraphs, lists, blockquotes, code blocks, and horizontal rules
- Default embedded CSS styling in generated HTML
- Sample Markdown input file for demonstration and testing

### Notes

- This version provides a simple subset of Markdown support and is intended for basic local conversion workflows.
